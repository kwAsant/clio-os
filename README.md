# Clio OS

Clio OS is an experimental custom infotainment interface and firmware emulation project for an aftermarket Allwinner F133-series car stereo installed in a 2008 Renault Clio.

## Project goals

- Develop a redesigned touchscreen interface.
- Emulate compatible Melis RTOS applications on a development computer.
- Investigate firmware, display, touch and peripheral compatibility.
- Test interface modifications without changing the physical stereo.

## Current status

The project is in early development. The emulator codebase is available, but compatible firmware for the target stereo has not yet been obtained or verified.

The original emulator was developed for an EKIY SK-8168 device. Compatibility with this project's target stereo is not yet established.
